# Cascade Popularity Prediction: Early-Adoption Features with LightGBM vs MLP

Motivation: "Deep Temporal Graph Learning for Cascade Popularity Prediction in Social Networks" (2025) argues that
modelling the temporal and structural spread of early adopters is key to forecasting how large an information
cascade will become. It proposes a transformer-plus-GCN hybrid, which is hard to reproduce faithfully without
its original data and PyTorch, so this experiment asks a narrower, testable question.

Question: Can a cross-validation-tuned LightGBM model on richer early-adoption features predict final cascade
popularity better than a neural network on basic early-spread features, when both are tested on the same
held-out simulated cascades?

Dataset: cascades simulated in code with an independent-cascade process on a Barabasi-Albert graph generated by
networkx. This is NOT the paper's own dataset (the paper's Twitter and Digg cascades have no verified public
download link), so `same_as_paper` is false.

Baseline vs improved:
- Baseline: scikit-learn MLPRegressor on early-spread features (cumulative adopter counts over the first few
  time steps). It stands in for the paper's neural temporal encoder and is not the paper's method.
- Improved: LightGBM regressor tuned by cross-validation on the training set, using the same early counts plus
  early-adopter degree statistics, growth rates and time-to-k-adopters.

Both models use the same single 80/20 split (seed 42), the same test set, and R2 on log final size as the main
metric, with Spearman correlation and MAE as secondary metrics. Each randomized model is run with seeds 42, 43 and 44.

## How to run

    pip install -r requirements.txt
    python analysis.py

Results: results are written to `results.json` (and a chart to `figures/`).
